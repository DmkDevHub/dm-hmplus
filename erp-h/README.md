# erp-h

products-erp-h 프로젝트를 보조하기 위한 작업 공간입니다.
임시 프로그램, 개발에 필요한 문서, 참고 자료를 관리합니다.

## 디렉토리 구조

```
erp-h/
├── docs/                 # 개발 문서
├── tools/                # 보조용 임시 프로그램 (도구)
├── scripts/              # 일회성 또는 반복 실행 스크립트
├── scratch/              # 임시 작업물, 실험 코드 (정리 대상)
└── reference/            # 외부 참고 자료, 다운로드 문서
```

## 디렉토리 용도

| 경로 | 용도 | 비고 |
|------|------|------|
| `docs/` | 공식 개발 문서 | 확정된 내용만 보관 |
| `tools/` | 재사용 가능한 보조 프로그램 | 사용법을 함께 기록 |
| `scripts/` | 자동화 스크립트 | 실행 방법 주석 필수 |
| `scratch/` | 임시 코드, 실험 | 주기적으로 정리 |
| `reference/` | 외부 자료 | 출처(URL 등) 기록 |

## 작성 규칙

- 문서 파일명은 소문자와 하이픈을 사용합니다. 예: `login-flow.md`
- 날짜가 중요한 문서는 파일명에 `YYYYMMDD` 형식을 붙입니다. 예: `20261109-회의록.md`
- 빈 디렉토리 유지를 위해 `.gitkeep` 파일이 들어 있습니다. 실제 파일이 생기면 지워도 됩니다.
